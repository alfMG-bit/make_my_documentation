Lo que se puede apreciar es que este archivo contiene todos los tipos de configuración para las bases de datos que Laravel puede trabajar. La variable que nos importa es ``default``.

```php
'default' => env('DB_CONNECTION', 'sqlite'),
```

Esta variable determina, por defecto, con que tipo de base de datos va a trabajar nuestro proyecto. Los proyectos Laravel (inclusive Laravel 12) trabajan con un archivo llamado ``.env``, en este archivo definiremos muchas cosas, pero entre ellas, también definiremos la base de datos con la que trabajaremos.

Dentro del archivo `.env` encontraremos las variables que debemos modificar para realizar una conexión a otra base de datos en lugar de SQLite, en este ejemplo, será a MySQL:

Archivo `.env`:

```env
DB_CONNECTION=sqlite
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=laravel
# DB_USERNAME=root
# DB_PASSWORD=
```

Modificamos y descomentamos variables: (ejemplo)

```env
DB_CONNECTION=mysql
# DB_HOST=127.0.0.1
# DB_PORT=3306
# DB_DATABASE=nombre
# DB_USERNAME=root
# DB_PASSWORD=123
```

Una vez se hayan configurado estas variables en el archivo `.env`,  no se debe de olvidar de ejecutar el siguiente comando en la consola, en la ruta del proyecto Laravel:

```shell
php artisan migrate
```

==**Cualquier error se debe verificar que la base de datos y el archivo `database.php` trabajen en el mismo `collation`, que por lo general es `utf8mb4_unicode_ci`**== 

# Crear una nueva migración en Laravel.

Para crear una nueva migración en Laravel, ejecutaremos el siguiente comando:

```shell
php artisan make:migration <aqui_nombre_migracion>
```
